CI/CD · CONTAINERS Projeto pessoal

DevOps Pipeline

↗

Pipeline de qualidade, testes e entrega de uma API em container.

O problema

Evitar que uma imagem seja entregue sem validar o código e o comportamento do container.

A implementação

API em Python/FastAPI, testes com pytest, lint e formatação com Ruff, build Docker e verificação HTTP dos endpoints /health e /version.

As decisões

Pull requests validam sem publicar. Na main, a pipeline entrega ao GHCR a mesma imagem testada, com identificação do commit. O container roda sem root e com restrições de escrita.

Python FastAPI Docker GitHub Actions pytest GHCR
