# Mariana Viana — Portfolio

Portfólio profissional bilíngue (português e inglês) com foco em Cloud, Platform Engineering e Developer Experience.

## Conteúdo

- Apresentação, experiência e tecnologias
- Formação, certificação e workshops
- Projetos e links para contato
- Layout responsivo e seletor de idioma

## Executar

Abra `index.html` no navegador ou sirva esta pasta com um servidor HTTP estático. Não há etapa de build nem dependências JavaScript.

## Arquivos

- `index.html`: conteúdo e traduções
- `style.css`: estilos e layout responsivo
- `script.js`: troca de idioma
- `portrait.jpg`: foto de perfil

As fontes são carregadas pelo Google Fonts.

## Hospedagem

Compatível com hospedagem estática. Na Vercel, use o preset Other, sem comando de build e com a raiz como diretório de saída.

A cópia publicada no Sites é gerenciada separadamente; alterações neste repositório não são sincronizadas automaticamente com ela.
