### Executar localmente

Clone o repositório:

```sh
git clone https://github.com/maridevops/portfolio-mariana.git
cd portfolio-mariana
```

Abra `index.html` no navegador. Para testar com HTTP, use um servidor estático de sua preferência. Se tiver Python instalado:

```sh
python -m http.server 8000
```

Acesse `http://localhost:8000/?lang=pt` ou `http://localhost:8000/?lang=en`.

Os arquivos na raiz podem ser publicados por um serviço de hospedagem estática, sem build. A versão no Sites é gerenciada separadamente: commits neste repositório não são sincronizados automaticamente com ela. Uma hospedagem conectada ao GitHub depende da configuração do respectivo provedor.

### Technology and local setup

The portfolio uses plain HTML, CSS and JavaScript. No framework, production JavaScript dependencies or build step is required. DM Sans and Space Grotesk load from Google Fonts.

Clone the repository and open `index.html`, or serve the root directory with a static HTTP server. With Python installed, run `python -m http.server 8000` and visit `http://localhost:8000/?lang=en`.

Use `?lang=pt` or `?lang=en` to share a specific language. The selected preference is stored locally when available. The résumé page preserves the selected language and provides a print button.

### Maintenance and hosting

Update both `data-pt` and `data-en` when editing translated content in `index.html` and `cv.html`. Keep the initial text in Portuguese. Check both languages, contact links and the résumé after changes.

Deploy the root directory to a static hosting provider without a build step. The Sites publication is managed separately; GitHub commits do not automatically update it. Any GitHub-connected hosting follows that provider's configuration.
